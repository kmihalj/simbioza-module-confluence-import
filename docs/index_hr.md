# Dokumentacija Simbioza Confluence importa

English index: [index_en.md](index_en.md)

Ovaj modul koristite kada administrator treba preseliti jedan Confluence XML izvoz spacea u Simbiozu. Namjerno nije opći klijent za sinkronizaciju Confluencea i nikada ne uvozi izravno iz aktivne Confluence instance.

## Sigurna zadana postavka

Zadani import uključuje aktualne stranice i privitke. Povijest, nacrti i obrisane stranice ostaju isključeni dok ih administrator izričito ne odabere. Neriješen korisnik ili grupa nikada ne dodjeljuju pristup.
